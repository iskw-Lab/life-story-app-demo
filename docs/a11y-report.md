**判定: 部分的に準拠**
- 基準は WCAG 2.2 AA（= ISO/IEC 40500:2025）と ISO 9241-171:2025 です。
- 判定の理由は、未確認の項目（「既知の制約・未確認」の節）が残っていることです。今回の確認では、A/AA で不適合のまま残した項目はありません。
- 本人向け画面（V3）の COGA 項目は、本人・ピアとの共同評価が終わるまで「要検証」とします。

## 実施した確認

1. **自動確認:** `.claude/skills/a11y-compliance/scripts/axe_audit.sh` を、THEME=light と THEME=dark の両方で全ルートに実行しました（axe-core 4.10.2、タグ wcag2a/2aa/21a/21aa/22aa）。
   - 修正前は、color-contrast・link-in-text-block・nested-interactive の違反がありました。
   - 修正後は、全ルート・両テーマで 0 件です。
2. **リフロー:** 320 CSS px 幅で全ルートの横スクロールを測定し、全ルート 0px でした。
   - V1 で一度不適合が見つかり、修正しました。
   - グラフ・表・V3 のサムネイル列の内部スクロールは、例外として許容しています。
3. **キーボード操作:** スクリプトで次を確認しました。
   - V1 のノードに Tab で移動すると、フォーカスリングとツールチップが表示される。Enter で選択でき、フォーカスは同じノードに残る。
   - 詳細パネルを開くと見出しにフォーカスが移り、Esc で閉じると元のボタンに戻る。
   - V3 の反応ボタンを押した後も、フォーカスは同じボタンに残る。
   - 会議画面の入力エラーでは、最初の未入力欄にフォーカスが移る。
4. **コントラスト計算:** トークンごとに計算しました。レイヤ配色は dataviz の検証スクリプトで確認しました（色覚多様性 ΔE は全ペアで合格）。
5. **COGA レビュー:** coga-person-view のチェックリストで V3 を確認しました。

## 既知の制約・未確認

- **実機のスクリーンリーダー:** VoiceOver / NVDA では未確認です。ARIA は付けましたが、実際の読み上げ順や冗長さは要確認です。
- **1.4.12 テキストの間隔:** 手動での確認がまだです。
- **1.3.4 表示の向き:** 縦向き・横向きに固定はしていません。タブレット実機では未確認です。
- **V1 の関係線:** 関係線の説明はホバーで表示されます。同じ内容は詳細パネルと V2 の関係一覧でキーボードからも読めるので、代替経路ありと判断しました。
- **絵文字:** 環境によって見た目が変わります。意味は必ず文字でも示しています。
- **読み上げ:** ブラウザの speechSynthesis（ja-JP）を使うため、端末によっては使えません。使えない場合はボタン自体を表示しません。
